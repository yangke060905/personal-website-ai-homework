# PRD：个人网站

## 1. 项目目标

建立一个内容真实、结构清晰、便于长期更新的个人网站，用于展示何超洋的个人简介、金融科技方向、产品研究、商业分析、数据工具、AI 系统学习和公开联系方式，并通过 GitHub Pages 对外发布。

## 2. 目标访问者

- 同学和教师：快速了解我在课程中的学习方向、项目成果和作业完成情况。
- 未来项目伙伴：判断我关注的方向、可协作的能力和项目兴趣。
- 实习或学习机会相关人员：了解我的基础技能、项目意识和公开联系方式。

## 3. 访问者最先寻找的信息

- 我是谁，以及我正在学习或探索什么方向。
- 我具备哪些真实技能、工具使用经验和业务理解。
- 我做过或正在推进什么项目，以及这些项目对应哪类能力信号。
- 如何通过 GitHub 等公开方式联系或了解我。

## 4. 希望访问者记住什么

访问者应记住：我是深圳大学金融科技专业学生，关注金融科技产品、财务与行业研究、数据驱动分析和 AI 协作系统。商业分析是方向之一，但我更希望把需求、数据、产品和工程理解连接起来。

## 5. 本期必须包含

- Hero：公开称呼、一句话定位、主要行动入口。
- About：真实个人简介、专业或学习方向。
- Skills：真实能力、工具或兴趣方向。
- Projects：展示财知道、财务数据风险识别与行业研究、金智研途三个项目或经历通道。
- Contact：至少包含 GitHub 主页链接。
- README、Design、Checklist、最终报告和截图证据。

## 6. 本期明确不做

- 不做登录、注册、数据库、支付或复杂后台。
- 不接入访客追踪、表单收集或任何需要密钥的外部服务。
- 不公开私人手机号、住址、课程邀请码、API Key、Token 或其他敏感信息。
- 不公开完整简历中的成绩排名、英语分数、详细实习时间线和未确认的私人联系方式。
- 不为了视觉特效引入复杂框架或无关依赖。

## 7. 成功标准

- GitHub Pages 链接可在无痕窗口打开。
- 五个基础区块齐全，内容真实，无模板占位。
- 桌面端和手机端均可读，无明显遮挡、溢出和死链。
- `README.md`、`docs/prd.md`、`docs/design.md`、`docs/checklist.md`、`report/final-report.md` 均存在且内容一致。
- `screenshots/` 至少保存 4 张关键证据截图。
- Git 仓库至少有 3 次有意义 commit。
- TA-Claw 预览无误，二次确认后看到 `Submitted successfully`。

## 8. 不能公开的信息

- 课程邀请码、作业代码、平台密码和个人反馈。
- 私人手机号、住址、身份证件、家庭信息。
- API Key、Token、`.env`、账号密码和未授权资料。
