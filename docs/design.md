# Design：个人网站设计说明

## 1. 页面结构与浏览顺序

页面采用单页滚动结构，顺序为：

1. Hero：姓名、个人定位、行动入口、能力关键词和右侧概览卡。
2. 作业流程条：Vibe、Spec、Harness、GitHub、Pages、TA-Claw。
3. About：个人简介和学习方向。
4. Skills：四组能力矩阵。
5. Projects：财知道、财务数据风险识别与行业研究、金智研途。
6. Experience：关键经历轨迹。
7. Contact：GitHub、报告和公开联系方式。

## 2. 视觉风格

- 风格关键词：成熟个人产品主页、金融科技作品集、清爽、可信、可验证。
- 主背景：软绿灰工作台 `#f3f6f2`。
- 主文字：深墨绿 `#17231b`。
- 主强调色：深绿 `#176b54`。
- 组件语言：紧凑导航、个人概览卡、证据条、能力地图、项目案例和经历路径，而不是海报式大字或暗黑科技模板。
- 字体：系统无衬线和等宽字体组合，保证 Windows、macOS 和移动端稳定显示。

## 3. 桌面端要求

- 首屏能直接看到姓名、定位、行动按钮、能力关键词和个人概览卡。
- 内容宽度限制在舒适阅读范围内，避免过长行宽。
- Skills 使用能力矩阵，Projects 使用案例研究卡片。

## 4. 移动端要求

- 导航在窄屏保持一行内可读或自然压缩。
- 区块顺序保持一致，文字不横向溢出。
- 能力地图、项目通道和经历轨迹在手机端改为单列。
- 页面没有强制动画；平滑滚动在 `prefers-reduced-motion` 下退化为普通跳转。

## 5. 关键文件说明

- `index.html`：页面内容、区块结构和链接。
- `assets/styles.css`：颜色、字体、间距、响应式布局。
- `assets/script.js`：更新年份和平滑滚动增强。
- `README.md`：项目说明、模板来源、Pages 链接和隐私说明。
- `docs/prd.md`：目标、范围、成功标准和隐私边界。
- `docs/design.md`：页面结构、视觉风格和文件职责。
- `docs/checklist.md`：可验证的验收清单。
- `report/final-report.md`：最终过程报告。
- `screenshots/`：桌面、手机、Pages 和 Checklist 证据截图。

## 6. 保留与修改策略

本项目使用自建轻量静态模板，因此不存在外部模板作者信息。后续修改应保持现有技术栈，优先补齐公开链接、截图证据和 GitHub Pages 发布，不引入无关依赖。

## 7. 图片和外部素材

当前版本使用不含真人身份信息的抽象金融科技视觉资产。若后续加入头像、项目图或背景图，必须记录来源与许可，并避免使用不适合公开的私人照片。

## 8. 公开信息取舍

网站公开适合课程展示和作品集访问的信息：姓名、学校与专业方向、能力概述、项目概述、部分实习与校园经历和公开链接。不公开课程邀请码、作业代码、平台密码、API Key、Token 或私人联系方式。
