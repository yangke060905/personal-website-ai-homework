# 个人网站规范化 AI 开发作业

这是 OPC-AI 培训营模块三的个人网站基础作业项目。项目采用静态 HTML、CSS 和 JavaScript 实现，目标是完成一个可通过 GitHub Pages 公开访问、内容真实、桌面端和手机端均可读的个人网站。

## 当前状态

- 网站结构：已建立 Hero、About、Skills、Projects、Contact 五个基础区块，并加入经历轨迹与作业流程证据链。
- 规格文档：已建立 `docs/prd.md`、`docs/design.md`、`docs/checklist.md` 初稿。
- 报告材料：已建立 `report/final-report.md`，发布信息等待 GitHub Pages 完成后补齐。
- 验证截图：已保存桌面端、手机端、项目区和 Checklist 等证据截图到 `screenshots/`。
- 附加作业：OpenClaw 双角色自动对话 APP 已放入 `additional/openclaw-dual-role-submission/`，并保留压缩包 `additional/openclaw-dual-role-submission.zip`。
- 待补充：GitHub 主页链接、GitHub Pages 链接和发布证据截图。

## 模板来源

本项目为课堂作业定制的轻量静态模板，由 Codex 根据作业要求搭建。视觉重做参考了 `taste-skill`、`impeccable` 和本地“前后端智能体系统学习”Vault 的结构表达，但未复制外部主题仓库代码。

## 本地预览

在项目根目录运行：

```powershell
python -m http.server 8000
```

然后在浏览器打开：

```text
http://localhost:8000
```
