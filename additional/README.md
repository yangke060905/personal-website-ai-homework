# 附加作业材料

本目录用于随主作业一并提交附加作业。

## OpenClaw 双角色自动对话 APP

- 解压版材料：`openclaw-dual-role-submission/`
- 压缩包：`openclaw-dual-role-submission.zip`
- 加分题 PRD：`openclaw-dual-role-submission/code/openclaw-dual-role-chat/docs/PRD.md`
- 最终报告：`openclaw-dual-role-submission/report/FINAL_REPORT.md`
- 评分点对照：`openclaw-dual-role-submission/report/SCORING_CHECKLIST.md`
- 截图：`openclaw-dual-role-submission/screenshots/`

说明：该附加作业主流程为 OpenClaw 真实生成通道；本地示例脚本仅用于课堂流程演示，不伪装成 OpenClaw 模型输出。
